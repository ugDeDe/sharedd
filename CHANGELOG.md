# Changelog

Все заметные изменения проекта. Формат — Keep a Changelog; версии
соответствуют тегам релизов.

## [Unreleased]

### Added

- **MTProto-проверка нод вместе с Globalping.** `[mtproto_check]` (токен — в
  панели: Настройки → MTProto-проверка): регистратор параллельно с
  верификацией Globalping вызывает внешний сервис (`POST /v1/check`), который
  делает настоящий fake-TLS хендшейк общим секретом пула и запрос до DC из РФ
  и снаружи. Карантин — только когда отрицательны обе проверки: Globalping
  провалена, но MTProto `OK` — нода считается доступной (событие
  `mtproto_rescued`); `DATA_CUT`/`RKN_BLOCK`/`MT_DEAD`/`DOWN` — отрицательно,
  `UNKNOWN` и сбой API — решает Globalping. Статус — тег MTP в списке нод.

- **Онлайн и RTT до DC2 в здоровье ноды.** Регистратор считает отчёт плохим,
  если нода не сообщает онлайн (`telemt_user_unique_ips_current`) или RTT ME
  до DC2 выше `[healthcheck] dc2_rtt_max_ms` (по умолчанию 3000 мс, 0 —
  выкл.); после `fail_threshold` таких отчётов подряд нода уходит из очереди
  (причина — в журнале и панели). Агент теперь всегда присылает снимок RTT
  по DC: mtdd — из `mtdd_me_ping_rtt_us`, telemt — из Control API
  (`[server.api]` его конфига, по умолчанию 127.0.0.1:9091) без смены
  вердикта; явный `[telemt] api_addr` по-прежнему включает критерий DC2.

- **Цена 1000 соединений.** Агент присылает CPU (в ядрах) и память самого
  процесса прокси (находит его по слушающему сокету общего порта: telemt,
  MEKO, MTProxyL, mtdd, mtproxy с воркерами), число ядер и объём RAM хоста.
  Регистратор раз в минуту пишет точку «соединения ↔ CPU/память/сеть»
  (`load_samples`, 48 ч) и считает среднюю и предельную (наклон регрессии)
  цену 1000 соединений. Публичная статистика: карточка на странице ноды и
  сравнение по типам прокси (медианы по нодам) на главной.

- **Рекламная пауза пула.** `[ad_pause] minutes_per_day` минут в сутки на
  весь пул ноды показывают рекламный тег пула вместо своего. Бюджет делится
  поровну между нодами с поддержкой, вверх до целых окон `master_ttl` (не
  меньше окна на ноду); окна мастерства ноды чередуются сквозь ротацию
  (реклама, своё, реклама…), выбранный бюджет — тишина до полуночи; добавление и удаление
  нод перераспределяет доли. Считается только подтверждённое время; агент
  применяет через mtdd `POST/DELETE /v1/ad-tag` без перезапуска и
  подтверждает состояние в heartbeat; включения/снятия — в журнале событий,
  расход за сутки по нодам и по пулу — в панели (Настройки → Реклама).
  Поддерживают mtdd с `/v1/ad-tag` (сразу для всех клиентов) и MTProxyL
  ≥ 1.4.9 с ME: агент ставит тег пула персональной меткой только общим
  пользователям пула (`mtproxyl secret adtag`, горячая перезагрузка без
  перезапуска), остальных пользователей и общую метку владельца не трогает,
  а при возврате восстанавливает прежние метки; состояние подтверждается по
  рабочему config.toml. Прочие ноды отмечаются «не поддерживает».

### Changed

- **Антискан: список собирает регистратор, только RU-адреса.** Регистратор
  раз в `[antiscan] interval_min` (по умолчанию 30 мин) скачивает
  abuse-листы из `[antiscan] sources` (адреса, подсети CIDR, диапазоны),
  оставляет только российские адреса и подсети (RIPEstat
  `country-resource-list`, `geo_url`) и раздаёт агентам: ревизия в `/config`,
  сам список — новый `GET /antiscan`. Агент больше не качает ipsum сам,
  загружает список в ipset `sharedd_scanners_net` (hash:net, поддерживает
  подсети) и снимает прежний `sharedd_scanners`. Без ответа регистратора
  действует последний применённый список (переживает перезагрузку через
  `/var/lib/sharedd/antiscan.list`). Настраивается в TOML и в панели
  (Настройки → Антискан, с состоянием сборки по каждому источнику).

- **CI/CD без ручных тегов**: push в `main` сам считает следующую версию
  (`scripts/next_version.sh`: `feat` → minor, `type!:`/BREAKING CHANGE →
  major, иначе patch), ставит тег `vX.Y.Z` и публикует релиз (он же
  `releases/latest`). Push в `dev` обновляет prerelease `dev` с версией
  `X.Y.Z-dev.<sha7>`. Ручной тег по-прежнему даёт релиз.
- **Веб-установщик ноды**: интерактивный выбор канала `main`/`dev`
  (`--channel=main|dev`; `stable` оставлен как синоним `main`).

### Added

- **Поддержка mtdd** (https://github.com/ugDeDe/mtdd) как типа ноды `mtdd`:
  агент читает порт и `/metrics` из `/etc/mtdd/config.json`, ходит в API с
  Bearer-токеном из `credentials.env`, переводит `mtdd_*` метрики в ключи
  регистратора (здоровье — сумма `mtdd_me_pool_ready`), синхронизирует
  пользователей через `/v1/users` и меняет `tls_domain` с рестартом
  `mtdd.service` и откатом. Установщики: `--preset mtdd` и автодетект.
  Runtime-смена `ad_tag` для mtdd пока не поддерживается.

## [1.0.3] - 2026-10-05

### Added

- **Возврат dead-нод**: класс `dead` больше не вечен. Агент после
  локального вердикта шлёт `/retire` (бан остаётся в вечной истории),
  самостоятельно ждёт оздоровления метрик (перепроверка раз в 30 с), затем
  перезапускается и регистрируется заново; регистратор снимает `dead`-
  запись первым же `/register` и проверяет здоровье с нуля. Число циклов
  возврата не ограничено.
- **CI-релизы**: workflow закоммичен (раньше `.github/` был в
  `.gitignore` и CI не запускался вовсе). Тег `vX.Y.Z`/`VX.Y.Z` собирает
  статические бинарники на GitHub-hosted раннере и публикует их в релиз;
  `releases/latest/download/...` для web-установщиков обновляется сразу.
- `golangci-lint` в CI собирается тем же тулчейном, что и проект, —
  готовый бинарник action падал из-за несовпадения версии Go с `go.mod`.

### Changed

- **Маска публичного IP**: первый и последний октет (`159.x.x.70`) вместо
  первых двух (`159.194.x.x`); ветка IPv6 удалена — пул IPv4-only.
- **Структура node**: по образцу registry — тонкий корневой `main.go`,
  вся логика в `internal/agent`, `internal/config` — зависимо-свободный
  лист (TOML, валидация, персистентность node ID).
- **MTProxyL**: режим superexpert заменён на динамическое управление через
  CLI (`secret add`, `expert set ...`, `expert apply`); конфиг и секреты
  приходят от регистратора, в инсталлерах не хардкодятся.

### Removed

- **Tombstone ноды** (`/var/lib/sharedd/terminated.json`): файл больше не
  существует, единственный источник правды о блокировках — регистратор.
  Перезапуск службы с устаревшим tombstone больше не «хоронил» ноду без
  перепроверки здоровья.

### Fixed

- Тест CLI-флоу MTProxyL (`TestApplySharedConfigViaMtproxylCLI`) падал и на
  main: гейт доступности CLI смотрит реальный PATH — теперь тест
  подкладывает фейковый бинарник.

## [Unreleased]

### Changed (refactor)

- **Структура registry**: монолитный `package main` (~8.6k строк) разделён на
  пакеты: тонкий корневой `main.go`, `internal/server` (вся логика),
  `internal/state` (владелец JSON-state-формата, без зависимостей),
  `internal/config` (TOML, валидация, hot-apply типы), `internal/history`
  (SQLite bans/events/traffic), `internal/machineapi` (wire-контракты с
  агентом + валидация запросов), `internal/globalping` (GET-клиент
  верификации), `internal/webassets` (сгенерированные страницы + шрифты).
  HTTP API, state-файл и SQLite-схема не изменились.
- **Селекция мастеров**: 315-строчный `evaluateAssignments` стал оркестратором
  над чистыми функциями (`sortQueue`, `pickLeastLoaded`, `rotateByTTL`,
  `reassignDead`, `fillEmpty`, `reconcileStints`) с табличными тестами;
  побочные эффекты собираются в `selectionSink`.
- **CI**: добавлены блокирующие gofmt, golangci-lint (registry/node/uigen),
  shellcheck (`-S warning`) всех скриптов, `build_ui.sh -check` и проверка
  парности установщиков (`check_installer_parity.sh`).
- **Web-установщики** сверяют sha256 скачанного бинарника (отсутствие файла
  суммы — предупреждение, расхождение — прерывание); node-web дополнительно
  проверяет ELF-магию.
- **systemd hardening**: registry — строгий профиль (ProtectSystem=strict,
  SystemCallFilter, CapabilityBoundingSet и др.), агент — консервативный
  (нужны iptables/ipset/systemctl). Юниты обновлены и в репозитории, и в
  heredoc'ах установщиков.

### Added

- Агент: pre-валидация пропатченного telemt.toml до записи (`validateTOMLText`)
  — битый патч отклоняется мгновенно вместо отката через нерестарт прокси.
- Агент: диагностика `TELEMT COMPATIBILITY` (не чаще раза в час), когда
  `/metrics` отвечает, но ключевые метрики отсутствуют — внятное указание на
  несовместимую сборку telemt вместо «metric not found».

### Fixed

- Парсер Prometheus-метрик агента: значения label'ов с `}`, `,` и escape-
  последовательностями больше не ломают разбор per-user серий.
- Установщик регистратора: флаг `--yes` задокументирован как no-op для
  совместимости (раньше — молчаливая мёртвая переменная).
- Тест `TestTrafficHistoryAndCounterReset`: детерминированные метки времени
  внутри календарного окна «Сегодня» (падал при запуске после полуночи).

### Removed

- Корневой скрипт `install-mtproto-antiscan.sh`: единственный владелец
  antiscan — агент ноды (`ANTISCAN_MTPROTO`, ipset `sharedd_scanners`);
  второй владелец той же задачи создавал дублирующие цепочки iptables.
