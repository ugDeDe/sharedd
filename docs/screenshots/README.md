# Скриншоты для README

Положите сюда PNG-файлы с указанными именами — они автоматически появятся
в [README.md](../README.md) (разметка с путями уже готова, искать места
по комментариям `📸` в тексте README).

| Файл | Что снять |
|---|---|
| `hero-panel.png` | Панель → «Обзор» (KPI-стрип + статистика пула) — главное изображение в шапке, ширина ~920 px |
| `panel-overview.png` | Панель → «Обзор» |
| `panel-nodes.png` | Панель → «Ноды» (таблица пула) |
| `panel-node.png` | Панель → страница ноды (чипы + GP по площадкам + графики) |
| `panel-dns.png` | Панель → «Мастера и DNS» |
| `panel-srmd.png` | Панель → «СРМД» (таблица «домен \| активные пользователи» + настройки) |
| `panel-events.png` | Панель → «Журнал» |
| `panel-settings.png` | Панель → «Настройки» |
| `statistics-node.png` | Публичная `/statistics/<node_id>` |
| `dashboard.png` | Публичный `/dashboard` (KPI + графики + таблица) |

Рекомендации: тёмная тема панели уже «из коробки», снимайте при ширине
окна ~1280–1440 px, чтобы таблицы не обрезались; в кадре лучше рабочий пул
(2–3 ноды, один мастер, пара событий в журнале).
