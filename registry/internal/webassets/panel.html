    Карантин · Globalping

    всё зелёное, кроме globalping — бан по IP после исчерпания попыток
    клик по строке — подробности, двойной — статистика ноды
    ← все ноды
    Клиенты считаются по общему секрету (только пользователи из shared_proxy.users). Звёздочкой помечены последние известные значения: живой мастер домена сейчас не присылает метрику. Ручной домен можно насильно отдать под контроль СРМД (кнопка «под СРМД») — тогда он сможет сворачиваться в CNAME при сжатии пула; домен СРМД кнопкой «в ручной» возвращается в ручной режим.

    Настройки СРМД

    применяются на лету и персистятся в registry.toml
    Когда нод больше, чем доменов × лимит, СРМД создаёт сиротские домены с инкрементом (shared1.…, shared2.… от основного) и сама дописывает их в managed-список; когда нод стало меньше — сворачивает лишние домены в CNAME на оставшиеся (созданные домены: нет). По умолчанию создание выключено.

      Пользователи

      квота, ключи, освобождение мест
      ЛогинРольКвотаЗанятоСтатусДействия
      Нельзя заблокировать последнего активного администратора. Уменьшение квоты не удаляет существующие ноды, но блокирует новые сверх лимита. «Освободить место» нужно, когда нода удалена физически.

      Квота по умолчанию

      выдаётся новому пользователю без явной квоты
      Целое 0..1000000. 0 = прежнее поведение (новый пользователь без квоты). Применяется к регистрациям по приглашению и к созданию из панели без явного значения.
      Значение хранится в конфигурации регистратора ([users] default_max_nodes) и применяется на лету. Уже созданных пользователей не затрагивает.

      Список мог устареть: последнее обновление не удалось.
      Ссылка приглашения показывается один раз при создании и не хранится в панели: потерянную ссылку нельзя вернуть — отзовите приглашение и создайте новое. Каждое использование приближает исчерпание; исчерпанное приглашение терминально. Отзыв не удаляет уже созданные аккаунты.

      Совместимость агентов

      общий Bearer-токен для машинных маршрутов
      Включено: старые агенты могут обращаться к регистратору с общим токеном на время миграции. Выключено: персональные учётные данные обязательны на всех машинных маршрутах, включая регистрацию, heartbeat, отчёты, retire и получение конфигурации. Сам переключатель не отправляет команду остановки прокси и не разрывает существующие соединения намеренно. Непереведённые агенты потеряют доступ к API; возможны последующие изменения доступности нод по обычным правилам пула.
