Подключение и установка выполняются на ваш существующий сервер по SSH. Новый сервер не создаётся и не оплачивается. «Повторить установку» использует тот же хост и ту же ноду — второй сервер не появляется. Нужен новый сервер у провайдера? Создать сервер — платный заказ у хостинга.

Ресурсы у провайдера

Серверы, созданные здесь у Nodehost, с тем же прогрессом установки, что и у своих хостов. Установка выполняется по SSH на уже созданный сервер — второй платный заказ не отправляется.

Мои профили

локальные профили · видны только вам
Nodehost · замена VPSBeget · только проектирование
Откройте по ID или после явного запуска профиля. Общего списка запусков API не предоставляет.
Локальные профили видны только вам. При создании сервера доступны и опубликованные профили, и ваши локальные (помечены «мой профиль»). Опубликованный профиль администратора можно скопировать себе кнопкой «Сделать копию» — копия станет вашим локальным профилем, доступным для правки. Сохранение обновляет профиль на месте. Шаги выполняются по SSH на вашем VPS; первый упавший шаг прерывает профиль. Переменные профиля ({{ var }}) подставляются в шаги на сервере; значения «секрет» маскируются в выводе операции.

Подключения

Секреты сохраняются в зашифрованном виде и наружу не отдаются. «Обновить баланс» не чаще одного раза в 60 секунд — более частый запрос вернёт сохранённое значение без обращения к провайдеру.
